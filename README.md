# CodeAlpha_Portfolio
# 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using **HTML, CSS, and JavaScript**.
This project showcases my skills, projects, and contact details with a clean UI and smooth animations.

---

## 🚀 Features

* ✨ Modern and attractive UI design
* 🌌 Animated particle background
* 💡 Mouse-follow glow effect
* 📱 Fully responsive (mobile-friendly)
* 🖼️ Project showcase with images
* 🔗 GitHub & Live project links
* 📄 Resume download button
* ⌨️ Typing animation effect
* 🎯 Simple contact form

---

## 🛠️ Technologies Used

* HTML5
* CSS3 (Flexbox, Animations, Glassmorphism)
* JavaScript (DOM manipulation, animations)

---

## 📁 Project Structure

```
portfolio/
 ├── index.html
 ├── style.css
 ├── script.js
 ├── resume.pdf (optional)
 └── images/ (project images)
```

---

## ▶️ How to Run

1. Download or clone the repository
2. Open the project folder
3. Open `index.html` in your browser

### OR

* Open folder in Visual Studio Code
* Use **Live Server** extension

---

## 📌 Customization

* Replace project images inside `images/` folder
* Update GitHub and Live links in `index.html`
* Add your own `resume.pdf`
* Modify About section with your details
